# وکیل‌یار هوشمند

نسخه اولیه وب‌اپلیکیشن فارسی برای ارائه اطلاعات عمومی حقوقی.

## امکانات نسخه اولیه
- رابط فارسی و راست‌چین
- بررسی سلامت سرویس در مسیر `/api/health`
- دریافت پرسش از مسیر `/api/chat`
- اتصال اختیاری به API سازگار با قالب OpenAI Chat Completions
- عدم نمایش پاسخ ساختگی در صورت تنظیم نبودن موتور هوش مصنوعی

## استقرار روی Vercel
1. مخزن `vakilyar-smart` را در Vercel وارد کنید.
2. Framework Preset را روی Other و Root Directory را روی `./` قرار دهید.
3. Deploy را اجرا کنید.
4. پس از استقرار، مسیر `/api/health` را باز کنید؛ باید پاسخ JSON با مقدار `ok: true` نمایش داده شود.

## محدوده نسخه آزمایشی
- در این نسخه فقط حوزه قضایی ایران پشتیبانی می‌شود؛ برای حقوق آلمان یا سایر کشورها از این نسخه استفاده نکنید.
- پاسخ‌ها اطلاعات عمومی‌اند و هنوز به بانک قوانین/آرای قضاییِ قابل جست‌وجو متصل نیستند؛ شماره مواد و منابع باید مستقل از متن پاسخ با منابع رسمی تطبیق داده شوند.

## فعال‌سازی موتور هوش مصنوعی
در Vercel از Settings > Environment Variables این متغیرها را تعریف کنید:
- `AI_API_KEY`: کلید محرمانه سرویس‌دهنده
- `AI_API_URL`: نشانی endpoint سازگار (اختیاری؛ پیش‌فرض OpenAI Chat Completions)
- `AI_MODEL`: نام مدل (اختیاری؛ پیش‌فرض `openai/gpt-oss-20b`)

پس از افزودن یا تغییر متغیرها، یک Redeploy انجام دهید. کلید API را هرگز در کد، مخزن عمومی یا گفتگو قرار ندهید.

## اجرای محلی
به Node.js نسخه 18 یا بالاتر و Vercel CLI نیاز است:
```bash
npm install -g vercel
vercel dev
```

## حریم خصوصی و محدودیت
این نسخه اطلاعات گفتگو را ذخیره نمی‌کند. پیش از استفاده واقعی، سیاست حریم خصوصی، امنیت، ثبت خطا، محدودیت نرخ درخواست و الزامات قانونی باید تکمیل و بررسی شوند. این سامانه جایگزین وکیل دارای پروانه نیست.
